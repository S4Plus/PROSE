# CUPID-ACT: 基于影响函数的 ACT 数据策划改进

## 快速要点
- 目标：在 ACT 策略上落地 CUPID 的“回报影响力”数据策划，直接提升闭环成功率。
- 核心贡献：把影响函数计算流程工程化为可复现流水线（影子训练 + 梯度缓存 + LiSSA + 筛选再训练）。
- 价值定位：相比仅做“质量筛选”的方法，CUPID-ACT 输出带符号影响值，可过滤有害演示并重加权关键演示。

## 问题与动机
- 传统数据质量度量（多样性、可预测性）与闭环回报不一致。
- 在线成功/失败信号虽直接，但粒度粗，难以归因到“哪些演示导致失败”。
- 需要一个“因果归因 + 可执行”的演示价值评估方法，适配 ACT 策略。

## 方法概述（CUPID-ACT）
- 阶段一：影子训练与梯度缓存
- 训练收敛的 ACT 影子模型。
- 对每个训练样本计算 L1 训练损失梯度并缓存。
- 用随机投影压缩梯度维度，降低存储与 I/O。

- 阶段二：混合评估与回报采集
- 在仿真/实机进行多次 rollouts，记录观察、潜变量、动作块。
- 在评估梯度阶段对 action 目标加噪（可选），增强估计稳定性。
- 记录每条轨迹回报并做中心化。

- 阶段三：影响力计算
- 用伪 Huber 构建回报梯度，避免与 ACT 结构不兼容。
- 通过 LiSSA 计算 H^{-1}g，得到可行的 influence 估计。
- 对每个样本输出带符号影响值：正值提升回报，负值拖累回报。

- 阶段四：数据策划与再训练
- 过滤负影响样本或重加权高影响样本。
- 重新训练 ACT，闭环验证收益。

## 相关工作评价与本文定位
- 相对 CUPID：
- CUPID 提出“回报影响力”范式，但原实现偏理论与特定架构。
- CUPID-ACT 把影响函数落地到 ACT，提供可复现工程链路，强调可运行与可扩展。
 - **CUPID 侧重提出范式，CUPID-ACT 强调工程可用性与策略适配**：针对 ACT 的观测‑动作结构、训练损失形式与数据管线做了完整对齐，使影响力估计能在真实训练中跑通。
 - **回报信号从“单一整体目标”扩展到可配置多回报**：CUPID-ACT 支持多回报列与加权汇聚，能把子任务/分阶段回报纳入影响函数计算，降低稀疏终回报带来的噪声。
 - **从“仅筛选”到“筛选 + 重加权 + 片段视角”**：除轨迹级影响分数外，CUPID-ACT 增加 window 级影响统计与权重/剔除机制，支持“保留轨迹完整性 + 局部坏段降权”的组合策略。
 - **工程效率与稳定性更可控**：通过梯度缓存、随机投影压缩与 LiSSA 配置化，CUPID-ACT 在实际预算内可复现，且可用 bootstrap 等手段评估影响估计稳定性。

- 相对 DemInf（互信息质量）:
- DemInf 适合无 rollouts 的快速质量筛选，但其指标与回报不一致，难以识别策略鲁棒性与虚假相关。
- CUPID-ACT 直接对回报归因，更贴近部署成功率。

- 相对 Demo-SCORE（成功/失败分类器）:
- Demo-SCORE 信号粗，难以精确定位“哪条演示有害”。
- CUPID-ACT 输出带符号影响值，可用于过滤、重加权与新增数据选择。

- 相对 SCIZOR（自监督局部策划）:
- SCIZOR 在状态-动作窗口级别做自监督过滤与去重，适合超大规模、无奖励/无标签数据的快速策划。
- CUPID-ACT 直接对回报归因，能识别“看似合理但导致失败”的演示策略，但需要 rollouts 与 HVP 计算预算。

- 相对其他离线质量/不确定性启发式:
- 这些方法多依赖静态统计，常与闭环表现脱节。
- CUPID-ACT 提供因果归因视角，能解释“失败由哪些演示驱动”。

## 对比结论（一句话定位）
- 如果只追求低成本筛质量：DemInf/启发式更轻量。
- 如果需要“闭环回报一致 + 可解释归因”：CUPID/CUPID-ACT 更合适。
- 如果面向超大规模、无标签数据做局部清洗与去重：SCIZOR 更合适。
## 我们工作所处位置与价值
- 位置：位于“闭环回报驱动的数据策划”谱系，强调因果归因而非静态质量。
- 价值：在 ACT 真实训练流程中可运行，兼顾可解释性（影响值）与可操作性（过滤/重加权/选择）。
- 适用场景：异质演示、存在策略偏差或虚假相关时，提升闭环成功率与鲁棒性。

## 创新性
- 影响函数范式在 ACT 上落地：将 CUPID 的“回报影响力”从理论方法转化为 ACT 可复现实用流水线。
- 带符号归因：输出正负影响值，支持过滤有害演示与重加权关键演示，而非仅做质量筛选。
- 工程可运行性：影子训练 + 梯度缓存 + 随机投影压缩 + LiSSA HVP，使影响力计算可在可控预算内执行。
- 统一损失设计：评估阶段用伪 Huber 对齐 ACT 训练目标，降低结构不兼容风险。
- 多回报与子任务对齐：支持多回报列与权重汇聚，将子任务/阶段性成功纳入影响估计，缓解稀疏终回报带来的噪声。
- 片段级信号与组合策划：引入 window 级影响统计与权重/剔除机制，支持“保留轨迹完整性 + 局部坏段降权”的策略组合。

## 改进思路
1. 估计稳定性：把回报从单一终回报扩展为分层/子任务回报（例如分解为若干可自动判定的子目标），让影响力梯度不再只依赖稀疏终回报。对高方差任务使用多次 rollout 重复估计，并显式记录每条演示的影响方差或置信度，用于自适应设置过滤阈值与重加权幅度。预期收益是减少估计噪声导致的错误剔除，但成本是评估时间增加。
2. 更细粒度归因：当前以轨迹聚合进行筛选，容易“误杀”包含关键片段的演示。可在动作块或片段级（如固定长度 window）计算影响力并做局部筛选，让数据分布既保留高价值片段，又移除导致失败的关键段。实现上可复用已缓存的样本级梯度，只需调整聚合策略与筛选粒度。预期收益是提升数据利用率，代价是筛选逻辑更复杂。
3. 计算效率：LiSSA 迭代成本是影响函数落地的主要瓶颈。可引入分块或低秩 Hessian 近似，在参数子空间上近似 H^{-1}g；或用增量更新策略，在数据策划后仅对受影响的样本局部更新 influence，而非全量重算。预期收益是更快迭代与更小计算预算，但需要额外验证近似误差对排序稳定性的影响。
4. 策略层融合：在混合质量数据中，纯回报影响力可能方差偏大。可以引入轻量质量指标作为正则项（例如动作可预测性或异常动作惩罚），与回报影响力做线性或自适应融合，用于抑制高噪声样本对排序的干扰。关键是把融合信号当作“降方差”而非“替代回报”，避免偏离闭环目标。
5. 鲁棒性导向：在 rollouts 中引入轻度分布移位（光照、物体质量、初始位姿扰动等），用“跨域回报”替代单域回报作为影响力信号，直接优化策略鲁棒性。这样能更准确识别“在训练域表现好但部署脆弱”的演示策略。代价是 rollout 条件更复杂，需要明确移位设计与评估标准。
6. 失败类型对齐：将失败按类型分桶（例如碰撞、卡死、抓取失败、路径偏差），分别计算影响力并对相应演示加权惩罚。这样可以让数据策划针对具体失败模式做定向修复，而不是仅做全局排序。需要在 rollouts 中加入失败类型的自动判别规则。
7. 选择与重加权联合：仅“过滤负影响”可能丢失多样性。可把负影响样本分为“可修复”与“不可修复”两类，对可修复样本降低权重而非删除，并对高影响样本做过采样或动态加权。这样在保持策略多样性的同时提升成功率，适合策略多样但噪声较高的任务设置。

## A 线落地（本轮实现）
1. 估计稳定性落地：支持分层/子任务回报与 bootstrap 重复估计，输出影响均值与方差。对应实现位于 `act/cupid_act_influence.py`，通过 `--reward_columns/--reward_weights/--reward_reduce` 与 `--bootstrap_samples/--bootstrap_seed` 控制。
2. 细粒度归因落地：在 episode 聚合之外，新增 window 级影响力统计并写入结果元数据。对应实现位于 `act/cupid_act_influence.py`，通过 `--window_size/--window_stride` 与 `--aggregate_mode` 控制。

## 风险与边界
- 需要 rollouts 与 HVP 计算成本，计算预算较高。
- rollouts 数量不足时影响估计噪声偏大。
- 若任务成功/失败判别困难，回报信号可能不稳定。

## 本文与相关工作对比（可直接引用）
- 相对 DemInf（互信息质量）：DemInf 以“动作可预测性+多样性”衡量质量，完全离线且成本低，但该指标与闭环回报不一致，难以识别鲁棒性与虚假相关导致的失败。本文直接以回报影响力做因果归因，输出带符号的样本影响值，能过滤有害演示并重加权关键演示，更贴近部署成功率。

- 相对 SCIZOR（自监督局部策划）：SCIZOR 用进度预测+去重在窗口级清洗超大规模数据，适合无奖励/无标签的快速策划；但不直接对齐回报，可能误删低进度但必要片段。本文以回报影响为核心信号，可识别“看似合理却导致失败”的演示策略，代价是需要 rollouts 与 HVP 计算预算。
- 相对启发式质量/不确定性方法：这些方法多依赖静态统计或模型不确定性，与闭环表现常有偏差。本文把影响函数落到 ACT 训练链路，提供因果归因与可操作的筛选/重加权策略。
- 相对原始 CUPID：CUPID 提出回报影响力范式，但实现偏理论与特定架构。本文将其工程化到 ACT：影子训练、梯度缓存、随机投影压缩与 LiSSA HVP，使影响力计算在可控预算内可复现落地。

## 论文 Related Work 段落（可直接粘贴）
相关工作主要围绕“如何在缺少可靠质量标签的情况下筛选或重加权演示数据”。一类方法以离线统计信号衡量质量，例如 DemInf 通过状态‑动作互信息刻画“可预测性+多样性”，以轨迹级分数进行筛选，适合无 rollouts 的快速数据清洗。另一类方法利用在线经验信号，例如 Demo‑SCORE 通过策略 rollouts 的成功/失败标签训练分类器，再以轨迹级阈值过滤不可靠演示，具有实现简单与信号直接的优势。自监督局部策划方法（如 SCIZOR）进一步将粒度下沉到窗口/样本级，使用任务进度预测剔除低进度片段，并结合视觉‑动作嵌入去重以减少冗余，适用于超大规模、无奖励/无标签数据。另有一批启发式方法基于不确定性、兼容性或训练损失等静态统计信号做筛选，成本低但与闭环表现的关联因任务而异。影响函数类方法（如 CUPID）则以回报为目标进行因果归因，输出带符号的样本影响值以支持过滤与重加权。
本文沿着“回报影响力驱动的数据策划”思路展开，创新点聚焦于将影响函数在 ACT 训练链路中可运行地落地（影子训练、梯度缓存、随机投影压缩与 LiSSA HVP），并提供带符号影响值以支持过滤与重加权。
